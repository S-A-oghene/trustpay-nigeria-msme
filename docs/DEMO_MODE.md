# Demo Mode

Demo Mode is deterministic and intentionally contains:

- Merchant 1: informal individual trader using a personal account.
- Merchant 2: registered company with registration evidence.
- Buyer 1: repeat buyer with multiple transaction context.
- Buyer 2: new buyer.
- Risk case: account change, amount mismatch, duplicate/replay event.
- Document case: missing/requested invoice, uploaded invoice, expired certificate.
- Obligation case: due in 7 days, expired, current/renewed.

All results are clearly labeled **DEMO / SIMULATED**. Demo Mode has no access to real customer funds or production credentials by design.
