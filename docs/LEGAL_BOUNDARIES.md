# Legal / Regulatory Boundaries

All user-facing legal pages and production claims require Nigerian legal/compliance review before launch.

TrustPay's base product is designed as an evidence, transaction-trust and business-control layer. It is not represented as a bank, deposit-taking institution, payment institution, escrow custodian, legal adviser, tax adviser, or universal fraud oracle.

Payment movement uses licensed provider infrastructure where a live integration is enabled. Protected settlement/escrow must only be activated through an appropriately regulated partner and approved commercial/legal model.

Registration, identity and transaction state remain distinct. A trader can be informal or use a personal receiving account without an automatic fraud finding.

No legal obligation should be enforced from a static code assertion when applicability or current law is uncertain. Use `POTENTIALLY_APPLICABLE` and request human/authority verification.
