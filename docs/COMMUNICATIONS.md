# Communication Fabric

TrustPay events are channel-neutral:

`Web · Browser notification · Email · SMS · WhatsApp · Push`

WhatsApp is an adapter, not the system of record. Sensitive identity collection stays on TrustPay's secure browser flows rather than ordinary chat.

A channel can be disabled because of outage, policy change, credential expiry, cost increase or user consent. The core workflow must remain intact and select an approved alternative channel.

**Constitutional rule:** WhatsApp is an optional communications adapter, never the core system of record.
