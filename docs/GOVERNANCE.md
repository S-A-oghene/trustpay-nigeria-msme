# Governance Kernel

## Authority order

Human constitutional rules → security/legal controls → organization controls → domain policy → workflow policy → agent policy → model/tool preferences → model suggestion.

## Four gates

High-impact actions pass:

`IDENTITY → AUTHORITY → POLICY → EVIDENCE`

## AI boundary

AI may classify, extract, summarize, explain and propose. It may not verify payment, release funds, change policy, declare fraud, delete audit records, reveal restricted information or grant privileged access.

## Risk classes

`R0` low-impact/read-only; `R1` routine reversible; `R2` external communication/workflow; `R3` business-control state; `R4` financial/security high-impact; `R5` constitutional/legal/safety-sensitive.
